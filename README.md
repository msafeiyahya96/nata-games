# 🌈 Nata Kids Games V3

Game edukasi interaktif usia **3–5 tahun**, dibuat untuk self-hosting di GitHub Pages.

## V3 Highlights
- Modern responsive UI: Bootstrap 5 + custom touch-friendly interface.
- English & Arabic: Animals, Colors, Numbers, Family + pronunciation.
- Little Coder: Patterns, Sequence, Direction, Robot Maze.
- ✏️ **Tracing** huruf A–E dan Hijaiyah awal dengan canvas sentuh.
- 🧠 **Memory Match** bonus game.
- 🎉 Confetti, stars, badges, level completion.
- 👨‍👩‍👧 **Parent Dashboard** untuk ringkasan progress lokal.
- 🎲 Quick random world.
- Progress menggunakan localStorage; tidak mengirim data anak ke server.

## Teknologi
HTML5, Bootstrap 5, CSS, vanilla JavaScript, Web Speech API, Canvas API. Tidak membutuhkan backend/database.
